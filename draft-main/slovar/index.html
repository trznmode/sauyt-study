Формулировки Booking простыми словами

Что пишут в Extranet и что это значит для ваших денег.

Genius

Программа лояльности Booking. Гостям-участникам даёте скидку/бонус — площадка чаще показывает вас «своим». Это не кнопка «стать №1», а обмен: скидка ↔ чуть больше спроса. Включать на гнилой карточке = дарить маржу впустую.

Visibility Booster / продвижение

Платите площадке за более заметное место в поиске (часто через повышенную комиссию на период). Работает как реклама: усиливает то, что уже кликабельно. Без фото и открытого календаря — дорогая пустышка.

Derived rate / производный тариф

Цена, которая считается от базовой (например −10% от стандартного). Удобно, чтобы не править 20 цифр вручную. Ошибка в базе = ошибка во всех производных.

Occupancy / загрузка

Какая доля номеров продана на дату. Смотрите не «красивый % за месяц», а дыры по дням недели.

ADR

Average Daily Rate — средний тариф за проданную ночь. Высокий ADR при пустых буднях ≠ победа.

RevPAR

Доход на номер (примерно ADR × загрузка). Ближе к правде, чем смотреть только цену или только %.

Stop sell

Закрыли продажи на дату. Нужен при ремонте/овербукинге. Если «забыли открыть» — вас нет в поиске, хотя объект работает.

Minimum stay

Минимум ночей (например 2). На пике событий — ок. На буднях без спроса — режет бронь.

Cancellation policy

Правила отмены. Жёсткая политика без гибкого тарифа = часть гостей уйдёт. Гибкая без цены = больше отмен.

Extranet

Личный кабинет объекта на OTA. Там календарь, цены, фото, отзывы, акции. «Не заходить» = карточка гниёт сама.

Channel manager

Сервис, который синхронизирует календарь/цены между площадками. Чтобы не продать один номер дважды руками.

Ranking / позиция в поиске

Не одна кнопка. Смесь: конверсия, отзывы, цена vs рынок, наличие дат, участие в программах. Лечится системой, не «магией».
